TeleSAPR, without installing it

The whole editor runs in this browser tab as WebAssembly: sketches, solids, drawings and the script console, with nothing sent to a server.

A large file is downloaded. The program is about 9 MB compressed (40 MB unpacked), fetched each time the page is opened unless your browser has it cached. On a slow or metered connection, you may want to wait for a better one.

  • A desktop browser with WebAssembly and WebGL works best: recent Firefox, Chrome, Edge or Safari. A phone or tablet is not a good fit.
  • The files you save are kept in the browser's storage, on this computer only. Download the ones you want to keep; clearing the site's data removes them, and so does a private window when it is closed.
  • The desktop program is faster and has everything; it is a free download.
