# The model and its files

- `pkg/sketch` is the one entry point for every change to a model: the window, a script and a
  file all call the same method, so a feature is first a method here, then everything else.
  Document state a feature adds goes into `UndoState` (`pkg/sketch/undo.go`), or it is lost on
  undo; every creating and editing action is one undo step and comes back identical on redo.
- The file format is `doc/tlspr-format.md`: anything a file holds is described there in the
  same commit. Load, regenerate, save gives the same bytes; a file of the previous format
  version still loads. `testdata/tlspr/golden` is regenerated by `scripts/regen-tlspr-golden.sh`
  and `testdata/tlspr/v1` never.
- `.slvs` is imported, never written. STEP files are linked as meshes or read as solids through
  `pkg/persist/link` and `pkg/persist/step`; their tessellations are cached only where
  `TELESAPR_CACHE_DIR` points.
- Exports (`pkg/export`) are checked against goldens under `testdata/export`; a golden there
  changes only in a commit of its own that says why.
