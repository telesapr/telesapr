# The window

- A feature's menu entry is a row of `pkg/ui/menu_table.go`, with an accelerator where one is
  free; it appears in the command search by itself. Creation is selection-driven: select, then
  invoke, and a message says what to select when the selection does not fit. Every parameter is
  on a text-window screen, editable in place, with expressions wherever a number is. Greying
  (`pkg/ui/menuenabled.go`) says when an entry does not apply.
- The user-facing sentence of an error is made here, from the lowercase fragment the engine
  returns.
- An interface scenario per feature is a script under `testdata/ui/scripts`, run on the
  headless platform (`pkg/platform/headless`); what it shows is the golden
  `testdata/ui/golden/<name>.goui` (`TestGoScripts`, regenerated by `scripts/regen-goui.sh`).
  `path_<name>.script` and `path_<name>.go` build the same model through the interface and a
  script and must save identical files (`TestPathEquivalence`); a path script must not save.
  `TELESAPR_UI_SCRIPT=name` prints what one script shows.
- The platforms: `pkg/platform/tkgui` is the X11 window, `pkg/platform/web` the browser
  (`cmd/telesapr-web`, `doc/dev-notes/browser.md`), `pkg/platform/headless` the tests'. Tests
  that open a window run only with `TELESAPR_GUI_TESTS=1` and `DISPLAY` (`make test-gui`).
- Renderers: `pkg/render/soft` draws in software, `pkg/render/gl` with OpenGL, `pkg/render/webgl`
  in the browser; PNG goldens compare them.
- The guide's pictures come from `doc/guide/scenarios` through `TestDocScenarios`
  (`scripts/regen-doc-images.sh`, `scripts/regen-guide-videos.sh`); a changed screen means
  regenerated pictures, in a commit of their own.
